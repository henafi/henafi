# Hi, I'm Henrik



I work on signal processing and analysis for incoherent scatter radar (ISR) — extracting ionospheric plasma parameters from raw radar voltage data.



### Projects



**[isr\_analysis](https://github.com/henafi/isr\_analysis)** — a processing pipeline for collective Thomson scatter radar data. It handles lag-profile inversion and long-pulse spectral fitting to recover electron/ion temperature, velocity, and density profiles, along with space-object contamination and RFI mitigation.



**[ionosci.org](https://ionosci.org)** — a learning resource on the ionosphere and the radio techniques used to observe it.
